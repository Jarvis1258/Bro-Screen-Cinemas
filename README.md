# Bro Screen Cinemas 🎬

**Bro Screen Cinemas** is a web-based cinema ticketing and management system developed using **ASP.NET and C#**. The system consists of two main modules: a Customer Module and an Admin Module, providing dedicated functionalities for customers and cinema administrators.

The customer interface allows users to browse available movies, explore cinema showtimes, and purchase movie tickets through an online booking system. Meanwhile, the administrative interface provides management capabilities for maintaining movie information, updating the movie database, and overseeing customer bookings.

This project was developed to apply my software engineering knowledge and gain practical experience in building a complete web-based application with both frontend and backend functionalities.

## 🎯 Project Objectives

- Develop a functional online cinema ticketing and management system.
- Provide separate interfaces and functionalities for customers and administrators.
- Implement database-driven movie and booking management.
- Apply Object-Oriented Programming (OOP) principles using C#.
- Gain practical experience in ASP.NET web application development.
- Understand the integration between frontend interfaces, backend logic, and databases.

## ✨ Key Features

### Customer Module
- **Movie Browsing:** Explore available movies and view movie information.
- **Movie Details:** View movie descriptions and relevant information.
- **Showtime Selection:** Browse available cinema showtimes.
- **Ticket Booking:** Select movie sessions and purchase cinema tickets.
- **Booking Management:** View and manage personal ticket bookings.
- **User Account Management:** Manage customer account information.

### Admin Module
- **Dashboard:** Access an overview of cinema operations.
- **Movie Management:** Add, update, and remove movie information.
- **Movie Database Management:** Maintain and manage the movie catalogue.
- **Showtime Management:** Manage movie screening schedules.
- **Booking Management:** View, monitor, and manage customer bookings.
- **Administrative Operations:** Maintain essential cinema system information.
